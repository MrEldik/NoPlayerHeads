NoPlayerHeads — prevent player head placement

A lightweight plugin that prevents players from placing player heads, including custom textured heads and heads used as collectible orbs. Both floor and wall placement are blocked.

Features:
- Silent protection: no chat messages.
- Works for all players, including operators and Creative mode.
- No commands, permissions or configuration required.
- No external plugin dependencies.

Installation:
1. Stop your server.
2. Put NoPlayerHeads.jar into the plugins folder.
3. Start the server.
